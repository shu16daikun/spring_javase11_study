# コーディング規約.md
（Java資格勉強_黒本学習システム開発 / 2025-10-25）

## 1. 総則

### 1.1 目的  
安全で保守しやすいシステムを実現するため、言語ごとの書式と記述ルールを統一する。  
目的は以下の3点：  
- 読みやすく、追えるコードを残すこと  
- DB・サーバ・ブラウザ間の責務を明確にすること  
- 意図の分かるコメントで自走可能にすること  

### 1.2 適用範囲  
全モジュール（Java / JS / CSS / HTML / SQL / properties / Test）に適用。  
**インデントは全言語タブ統一**とする（例外はYAMLのみ2スペース）。

---

## 2. Java実装規約

### 2.1 構造・行数・ネスト

| 項目 | 規定値 | 備考 |
|------|--------|------|
| 1行最大文字数 | 100文字 | 改行優先（引数は1引数/行で折返し） |
| ファイル行数 | 1,000行目安 | 超過時は分割を検討 |
| メソッド行数 | 80行上限（40目安） | 小分割・早期return |
| ネスト深さ | 2段まで | 3段目はガード節で脱出 |
| 循環的複雑度 | 10以下 | 超過時はメソッド分割 |

## 10. Eclipse Code Templates（最終版 / 2025-10-25）

### A. Comments（コメント）

#### A-1. Files（filecomment）
```java
/*
 * ${file_name}
 * Project : ${project_name}
 * Package : ${package_name}
 * Author  : ${user}
 * Created : ${date} ${time}
 *
 * 目的:
 * - ${todo}
 *
 * 注意:
 * - 文字列定数は private static final String（規約）
 */
```

#### A-2. Types（typecomment）
```java
/**
 * ${type_name}
 * 目的: ${todo}
 *
 * 公開契約:
 * - 例外は userCode のみ外部に出す（内部構造は伏せる）
 *
 * 備考:
 * - DTO は record（Java 21）
 */
```

#### A-3. Fields（fieldcomment）
```java
/** ${todo} */
```

#### A-4. Constructors（constructorcomment）
```java
/**
 * コンストラクタ（${enclosing_type}）
 * 目的: ${todo}
 *
 * ${tags}
 *
 * 意味:
 * - @param <name> : 〜（引数の意味）
 * - @throws <exception> : 〜
 */
```

#### A-5. Methods（methodcomment）
```java
/**
 * 意味:
 * - @param <name> : 〜（引数の意味／単位／許容範囲など）
 * - @return : 〜（戻り値の意味／不変条件）
 * - @throws <exception> : 〜（いつ／なぜ投げるか）
 */
```

#### A-6. Overriding methods（overridecomment）
```java
/**
 * 意味:

 * - @throws <exception> : 〜（いつ／なぜ投げるか）
 */
```

### B. Code（コード本体）

#### B-1. New Java files（newtype）
```java
${filecomment}
${package_declaration}

/* ===== [import] START ===== */
// import は明示指定（ワイルドカード禁止）
/* ===== [import] END ===== */

${typecomment}
${type_declaration}
```

#### B-2. Class body（classbody）
```java

	/* ===== [constants] END ===== */

	/* ===== [fields] START ===== */

	/* ===== [public/protected] END ===== */
```

```java
	/* ===== [constants] END ===== */
```

### 補足
- ${cursor} は Eclipse 環境では未サポートのため、区切りコメントで代用。  
- 保存時整形と EditorConfig (.editorconfig) の内容を必ず有効化。  
- Code Templates の Export / Import は Eclipse 設定画面右下から実施可能。  

---

### 差分概要（v1.4 更新点）
- `typecomment`：責務項目を削除、公開契約・備考のみへ簡略化。  
- `methodcomment` と `overridecomment` の記述統一。  
- `catchblock`／`methodbody`／`constructorbody` に Eclipse 自動生成コメントを反映。  
- 各 body テンプレート（class/interface/enum/record）を codetemplates.xml と一致化。
