## 1. 概要

### 1.1 目的  
安全で保守しやすいシステムを実現するため、言語ごとの書式と記述ルールを統一する。  
目的は以下の3点：  
- 読みやすく、追えるコードを残すこと  
- DB・サーバ・ブラウザ間の責務を明確にすること  
- 意図の分かるコメントで自走可能にすること  

### 1.2 適用範囲  
全モジュール（Java / JS / CSS / HTML / SQL / properties / Test）に適用。  
**インデントは全言語タブ統一**とする（例外はYAMLのみ2スペース）。

---

## 2. Java実装規約（抜粋）

| 項目 | 規定値 | 備考 |
|------|--------|------|
| 行最大長 | 100文字 | 改行優先（引数は1引数/行で折返し） |
| メソッド行数 | 80行上限（40目安） | 小分割・早期return |
| ネスト深さ | 2段まで | 3段目はガード節で脱出 |
| 定数 | `private static final String` 形式。マジック値禁止 |
| コメント | 「目的」「意味」「契約」を明示 |
| import | 明示指定（ワイルドカード禁止） |
| DTO | record（Java21）で定義 |
| 否定条件 | isNotXxx() を使用 |
| static利用 | 純関数のみ。状態保持禁止 |

## 4. 運用ルール

* `import` は必ず**明示指定**。ワイルドカード禁止。
* 保存時整形（Format / Organize imports / Add missing @Override）をON。
* コメントは **目的 → 意味 → 契約** の順で記述。
* DTOはrecord、条件式はMyType、否定はisNotXxx。
* AOP対象クラスはpublic非final。
* `.editorconfig` と Eclipse の Save Actions を同期。
* 新規メソッドは `/**` → Enter でテンプレを展開し、“意味ブロック”を必ず埋める。

---

## 5. 設定手順（Eclipse）

1. **Preferences → Java > Code Style > Code Templates**

   * 「Import」→ このテンプレXMLを指定。
2. **Java > Editor > Save Actions**

   * Format source code
   * Organize imports
   * Add missing @Override
3. **EditorConfigプラグイン** をONにし、`.editorconfig`を尊重。
